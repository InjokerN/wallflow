导入壁纸

支持单文件、Wallpaper Engine 文件夹、ZIP 整包（含 project.json 自动识别）

可一次选多个 / 直接把一堆文件夹或 ZIP 拖进这个框，按顺序逐个导入

单文件最大支持 2GB；WE 整包会保留原文件夹结构与 project.json

导入说明

能不能收录，只看包里有没有这些东西

WE 文件夹 / ZIP 怎么认

只认 project.json：type 决定场景／视频／网页，file 指定主文件，preview 指定封面。外面套几层文件夹都能找到它，包里的系统垃圾（__MACOSX、.workbuddy）会被丢掉。

单文件怎么认

按扩展名归类：.mp4／.webm 进视频，.html 进网页，图片进场景。适合只有一张图或一段视频的情况；孤立的一个 html 没有配套资源，画面多半是空的。

这些导不进来

依赖型壁纸（本体在另一个壁纸里）、没有 project.json 的 WE 包、7z／rar 压缩包。同名壁纸已在库里时只提示「已有」，不会生成第二份。

常规设置

需要在应用内修改
开机时启动 WallFlow登录 Windows 后自动启动，壁纸随之恢复
启动时最小化到系统托盘启动后不弹出主窗口，点托盘图标再打开
关闭窗口时最小化到托盘关掉主窗口后壁纸继续运行；关掉这项则关闭即退出程序
全屏应用时暂停壁纸检测到游戏或全屏视频时暂停，退出全屏后自动恢复

暂停时释放内存开启=真正卸载解码器释放显存（推荐，接近 WE 的 Stop）；关闭=只暂停保留画面，恢复更快但占内存
指定程序运行时暂停填入 exe 文件名（如 game.exe），这些程序运行期间壁纸自动暂停并释放内存，全部退出后恢复。只认精确文件名、不看安装路径（WE 同款口径）
列表每页行数壁纸库/收藏/发现页按行数分页：每页数量 = 当前列数 × 这里的行数，窗口越宽一页显示越多
